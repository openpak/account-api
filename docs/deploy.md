# Deploy: account-api

A Go library, not a service. Consumers add it with `go get github.com/openpak/account-api@<tag>` and import `github.com/openpak/account-api/openpak/account/v1`.

Releases are `vX.Y.Z` tags. Regenerate with `scripts/generate.sh` after editing a `.proto` file, then commit the `.proto` and generated files together.
